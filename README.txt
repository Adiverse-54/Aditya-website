ADITYA RAJ PERSONAL WEBSITE — BEGINNER SETUP
=============================================

FILES
-----
index.html   = page content
style.css    = design and layout
script.js    = JavaScript interactions and contact form
myphoto.jpg  = your own photo (you add this file)

PART 1 — OPEN THE WEBSITE ON YOUR COMPUTER
------------------------------------------
1. Put index.html, style.css, script.js and myphoto.jpg in the SAME folder.
2. Double-click index.html to open it in Chrome.
3. Dark mode and typing animation should work.
4. The contact form will NOT save messages until you complete Part 2.

PART 2 — CONNECT A FREE BACKEND DATABASE WITH SUPABASE
-------------------------------------------------------
1. Open https://supabase.com/ and create an account.
2. Create a new project. Save the database password somewhere safe.
3. In your project dashboard, open SQL Editor and create a new query.
4. Paste and run the SQL below:

create table if not exists public.contact_messages (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 2 and 80),
  email text not null check (char_length(email) between 3 and 160),
  message text not null check (char_length(message) between 5 and 3000),
  created_at timestamptz not null default now()
);

alter table public.contact_messages enable row level security;

revoke all on table public.contact_messages from anon, authenticated;
grant insert on table public.contact_messages to anon;

create policy "Visitors can submit contact messages"
on public.contact_messages
for insert
to anon
with check (
  char_length(name) between 2 and 80
  and char_length(email) between 3 and 160
  and char_length(message) between 5 and 3000
);

5. In Supabase project settings, find the API or Connect section.
   Copy the Project URL and the publishable/anon public key.
   NEVER use the service_role or secret key in a public website.
6. Open script.js in Notepad.
7. Find these two lines:
   const SUPABASE_URL = "PASTE_YOUR_SUPABASE_PROJECT_URL_HERE";
   const SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE";
8. Replace the text inside the quotes with your Project URL and publishable/anon key.
   Keep the quotation marks.
9. Save script.js and refresh index.html in Chrome.
10. Submit a test message. In Supabase, open Table Editor and look at contact_messages.

SECURITY NOTES
--------------
- The public website can submit messages, but the SQL above does not grant public permission
  to read submitted messages.
- The anon/publishable key is designed for browser use when Row Level Security is configured.
- Never put a database password, service_role key, or secret key in HTML or JavaScript.
- A public form can attract spam. Before using it widely, add CAPTCHA/rate limiting or move
  submission through a server-side function.
- Do not collect sensitive personal information in this demo form.

PART 3 — DEPLOY ONLINE
----------------------
Upload the whole website folder to your hosting service (for example Netlify Drop).
The folder should contain index.html at its top level, plus style.css, script.js and myphoto.jpg.
After changing any file, upload the updated folder again to publish your changes.

CUSTOMIZE
---------
- Change visible text in index.html.
- Change colors and spacing in style.css.
- Change the rotating phrases in script.js in the `phrases` array.
